# Roadmap

Темп: ~10–15 ч/неделю. Каждый этап заканчивается рабочей версией, задеплоенной и описанной в README.

## Этап 1: ядро домена (нед. 1–2)
- [x] Схема БД и миграции Flyway: tenant, staff, service_offering, booking
- [x] Запрет двойной записи через `EXCLUDE`-ограничение и тест на конкурентность
- [x] REST API: компании, мастера, услуги, бронирования, отмена
- [x] Problem Details для ошибок, Swagger UI, Actuator
- [x] Docker, docker-compose, GitHub Actions
- [x] **Spring Security + JWT**: регистрация владельца, роли `OWNER` / `STAFF`, tenant берётся из токена, а не из URL
- [x] Расписание мастеров (рабочие часы, выходные) и проверка, что запись попадает в рабочее время
- [x] Эндпоинт свободных слотов: `GET /availability?serviceId=&date=`
- [ ] Пагинация списков

## Этап 2: MVP в продакшене (нед. 3–4)
- [x] Деплой: Render (приложение) + Neon (PostgreSQL), HTTPS, переменные окружения — https://slotly-minx.onrender.com
- [x] Публичная страница записи по `slug` без авторизации (`/b/{slug}`), отмена по ссылке с токеном
- [ ] Клиенты как сущность (CRM): история визитов, заметки
- [x] Защита публичных эндпоинтов: rate limiting (Bucket4j) по IP, email, бизнесу; лимит записей на телефон
- [ ] Row-Level Security в PostgreSQL как второй уровень изоляции tenant'ов

## Этап 3: фронтенд (нед. 5–6)
- [ ] React + TypeScript + Vite, TanStack Query
- [ ] Кабинет владельца: календарь записей, мастера, услуги
- [ ] Публичный виджет записи для клиента

## Этап 4: асинхронность (нед. 7–8)
- [ ] Transactional outbox, затем Kafka (событие `BookingCreated`)
- [ ] Отдельный notification-service: Telegram-бот и email, напоминание за 24 ч
- [ ] Redis: кеш свободных слотов, общее хранилище rate-limit-бакетов для нескольких инстансов

## Этап 5: бизнес-фичи и полировка (нед. 9–10)
- [ ] Платежи (Stripe/ЮKassa в test mode), тарифы и подписки
- [ ] Отчёты: выручка, загрузка мастеров (SQL-аналитика, оконные функции, материализованные представления)
- [ ] Prometheus + Grafana, OpenTelemetry
- [ ] Нагрузочный тест (k6 или Gatling), результаты в README
- [ ] Скриншоты, демо-гиф, ссылка на живой стенд
